# Beagle Information Page

A simple responsive HTML/CSS project with three sections: introduction, Beagle image, and trivia.

## Run locally
1. Extract the project folder.
2. Open `index.html` in a browser.

## Files
- `index.html` — page structure, metadata, links, image, and ordered trivia list.
- `style.css` — page styling and responsive layout.
- `favicon.svg` — browser tab icon.

The Beagle photograph is loaded from Wikimedia Commons (Beagle-dog.jpg, CC0): https://commons.wikimedia.org/wiki/File:Beagle-dog.jpg
